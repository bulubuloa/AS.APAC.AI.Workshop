Notes

1. Complete web workflows: Our tests need to follow a whole business process, such as creating a vendor or opening a job in another tab. Playwright can check these steps together, including the related service responses.

2. Understanding failures: A failed test should show what went wrong. Playwright records the steps, screenshots and page state, helping QA identify the cause and explain it clearly.

3. Day-to-day maintenance: Web pages may take different amounts of time to load. Playwright waits for controls to be ready, reducing failures caused by timing. Changes to business rules or page controls still need test updates.

4. Cost and license: All three core tools are free to use under their open-source licenses. Playwright includes the reporting features we need without a required paid service. Running and maintaining the tests still has a cost.

5. Project fit: RoadSide and Benefit need complete workflow checks and evidence that QA can review. Playwright combines these capabilities in one framework, making it a suitable choice for our web testing.
