The local report gate was checked with five policy fixtures: accept a clean run; reject failure, skip, empty run and incomplete pack. It parsed the saved RSA report (6 tests, all green) and correctly rejected it when the required full workshop pack was set to 13. It accepted the saved Benefit report when its expected size was 2. This proves local result consumption and pack completeness policy, not cloud execution.

CodeBuild officially supports JUnit reports. Its buildspec defines report groups/artifacts and supports secret references; VPC-enabled builds can reach private resources with the required network configuration. See CodeBuild test reports, buildspec reference and VPC support. Playwright documents browser installation and CI execution in its CI guide.

Keep credentials and auth state out of source and shared reports. Restrict trace/video artifacts because they can capture tokens and customer data.
